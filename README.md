# Flame Test

A self-judged flashcard game for 2,359 NCERT chemistry one-liners (JEE Main & Advanced):
p-Block, d- & f-Block, Periodic Table, Chemical Bonding and Coordination Compounds.

- See only the question. Tap **I know it** to move on, or **Show answer** if you forgot.
- **Set aside** sends a card to your tough pile; three "I know it" in a row clears it.
- XP levels run from hydrogen (1) to oganesson (118). Progress is saved in your browser.

Static site: `index.html` + `data/*.json`. No build step.
