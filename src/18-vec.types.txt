## If this type comes, solve like this
Q: If a vector $\vec c$ is defined by cross/dot conditions ($\vec c\times\vec b=\vec a\times\vec b$, $\vec c\cdot\vec a=k$)
F: \vec c\times\vec b=\vec a\times\vec b\Rightarrow\vec c=\vec a+\lambda\vec b;\ \ \text{find } \lambda \text{ from the dot condition}
N: For $\vec a\times\vec c=\vec b$ type: cross both sides with $\vec a$ and use BAC–CAB.
P: 29:1,5,17,25,26,27,47,48,49,55,68

Q: If magnitudes and a dot product are given and $|\vec a+t\vec b|$ etc. asked
F: |\vec u|^2=\vec u\cdot\vec u;\ \ |\vec a\times\vec b|^2=|\vec a|^2|\vec b|^2-(\vec a\cdot\vec b)^2
P: 29:8,14,16,22,45,62,65,66,67,70,71

Q: If projection or angle between vectors is asked
F: \text{proj}_{\vec a}\vec b=\frac{\vec a\cdot\vec b}{|\vec a|^2}\vec a;\ \ \cos\theta=\frac{\vec a\cdot\vec b}{|\vec a||\vec b|}
P: 29:9,35,36,37,42,43,54,59,41

Q: If coplanarity / scalar triple product / volume
F: [\vec a\ \vec b\ \vec c]=0\ \text{(coplanar)};\ \ V=|[\vec a\ \vec b\ \vec c]|;\ \ [\vec a\times\vec b\ \ \vec b\times\vec c\ \ \vec c\times\vec a]=[\vec a\vec b\vec c]^2
P: 29:11,12,15,46,50,72,73,77,78

Q: If triangle area/medians/position vectors in 3D
F: \text{area}=\tfrac12|\vec{AB}\times\vec{AC}|;\ \ \text{centroid}=\tfrac{\vec a+\vec b+\vec c}3
P: 29:23,24,32,33,34,39,40,44,56,57,58,61,64,63,60,53,29:69
