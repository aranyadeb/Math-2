## If this type comes, solve like this
Q: If it is binomial: independent trials, "at least", mean/variance
F: P(X=r)={}^nC_rp^rq^{n-r},\ \ \mu=np,\ \sigma^2=npq,\ \ P(X\ge1)=1-q^n
N: Minimum trials: solve $1-q^n\ge$ target. Given ratio $3P(X=0)=P(X=1)$ ⇒ $\frac{np}{q}=3$.
P: 27:2,4,11,15,16

Q: If Bayes / total probability (which bag, which city, which coin)
F: P(E_i|A)=\frac{P(E_i)P(A|E_i)}{\sum P(E_j)P(A|E_j)}
N: Draw a tree. Words like KANPUR/ANANTPUR: likelihood = probability two consecutive letters read "AN" in each word.
P: 27:3,6,14,22,23

Q: If a random variable distribution / expectation is asked
F: \sum p_i=1,\ \ E(X)=\sum x_ip_i,\ \ \operatorname{Var}=E(X^2)-E(X)^2
N: Without replacement (defectives in a sample): hypergeometric $P(X=r)=\frac{{}^DC_r\,{}^{N-D}C_{n-r}}{{}^NC_n}$.
P: 27:1,10,24,27,35,37,42,43

Q: If two players alternate until an event occurs
F: P(A\ \text{wins})=\frac{p}{1-(1-p)(1-q)}
P: 27:9

Q: If counting-based probability (numbers, words, functions, matrices, coefficients)
F: P=\frac{\#\text{favourable}}{\#\text{total}}
N: Use P&C carefully; for "roots real" count $(a,b,c)$ with $b^2\ge4ac$.
P: 27:5,7,8,12,17,18,25,26,28,29,30,31,38,39,40,36

Q: If events with conditions on intersections (pairwise independent, exactly one)
F: P(\text{exactly one of } A,B)=P(A)+P(B)-2P(A\cap B)
P: 27:13,19,20,34,41,21

Q: If geometric probability on intervals
F: \text{area of favourable region in the square } [0,a]^2 \text{ divided by } a^2
P: 27:32,33
