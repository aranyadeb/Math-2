Q: If it asks the rank (serial number) of a word in dictionary order, or the word at a given rank
R: "All letters of PUBLIC are arranged as in a dictionary; find the serial number of PUBLIC", or "the 50th word".
F: \text{rank}=1+\sum(\text{letters smaller than the current one, still unused})\times(\text{remaining places})!
S: Write the letters in alphabetical order. || For the first place, count the unused letters smaller than the word's first letter; each one starts $(n-1)!$ words. || Fix the actual first letter and repeat for the second place with $(n-2)!$, and so on. || Add everything and add $1$ for the word itself. || With repeated letters, each block is $\frac{(\text{remaining})!}{\text{repeats}!}$ instead of a plain factorial. || For "the $k$-th word", subtract block sizes from $k$ until you land inside a block.
E: PUBLIC (B,C,I,L,P,U): B,C,I,L first → $4\cdot120=480$; P then B,C,I,L before U → $4\cdot24=96$; PUB; then C,I before L → $2\cdot2=4$; then C before I → $1$. Rank $=480+96+4+1+1=582$.
H: Trap: forgetting the final "+1", and using letters that have already been used.
