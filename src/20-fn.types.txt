## If this type comes, solve like this
Q: If a relation on a small set is described and the number of its elements (pairs) is asked
R: "$xRy$ iff $2x+y\le2$ on $\{-2,\ldots,4\}$", "$(a,b)R(c,d)$ iff $2a+3b=3c+4d$", "$(x,y)R(z,w)$ iff $x\mid z$ and $y\le w$", "$R_1=\{(p,p^n)\}$".
F: n(R)=\sum_{x}\#\{y:(x,y)\in R\}
S: Fix the first element $x$ and list all $y$ that work. || Add the counts over $x$. || For relations on $A\times A$ with independent conditions on the two coordinates, multiply the two counts. || Read off minimal/maximal properties (domain, range) from the list.
E: $x\mid z$ on $\{2,\ldots,6\}$: $3+2+1+1+1=8$ pairs; $y\le w$: $15$ pairs; total $8\times15=120$.
P: 04:1,9,11,12,8

Q: If the minimum number of pairs to add to make a relation reflexive/symmetric/transitive/equivalence is asked
R: "Minimum elements to add to $\{(a,b),(b,c),(b,d)\}$ to make an equivalence relation", "make $R=\{(x,y):\ln(x+y)\le2\}$ transitive".
F: \text{equivalence classes}: \text{an equivalence relation with classes } C_i \text{ has } \sum|C_i|^2 \text{ pairs}
S: For an equivalence relation, find which elements must end up in the same class (linked by any chain). || Count $\sum|C_i|^2$ and subtract the pairs already present. || For transitivity, list all pairs $(a,c)$ forced by $(a,b),(b,c)$ that are missing; repeat until nothing new appears.
E: $a\sim b\sim c$, $b\sim d$: one class of 4 elements → 16 pairs; add $16-3=13$.
P: 04:4,17

Q: If you must decide whether a relation is reflexive, symmetric, transitive or an equivalence
R: "$\gcd(a,b)=1$, $2a\ne b$", "$3ad-7bc$ is even", "$A\triangle B=\emptyset$ on the power set", "$3x+\alpha y$ multiple of 7 is an equivalence iff…", "$1+ab>0$".
F: \text{R: } (a,a)\in R\ \forall a;\ \ \text{S: } (a,b)\Rightarrow(b,a);\ \ \text{T: } (a,b),(b,c)\Rightarrow(a,c)
S: Test reflexive with a general $a$ (and find a failing example). || Test symmetric by swapping. || For transitive, try small counterexamples (e.g. $\gcd(2,3)=\gcd(3,4)=1$ but $\gcd(2,4)=2$). || For parameter questions, impose reflexivity first; it usually fixes the parameter, then check the rest. || Count equivalence classes when asked (e.g. $\frac ab=\frac cd$ classes are fractions).
E: $3x+\alpha x\equiv0\pmod7$ for all $x$ ⇒ $\alpha\equiv4\pmod7$; then $3x+4y\equiv0\iff x\equiv y$, an equivalence.
P: 04:2,3,5,6,10,18

Q: If the number of relations with given properties is counted
R: "Symmetric relations on $\{1,2,3,4\}$ that are not reflexive", "reflexive and transitive but not symmetric, containing $(1,2)$, at most 6 elements".
F: \text{relations on } n:\ 2^{n^2};\ \text{reflexive}: 2^{n^2-n};\ \text{symmetric}: 2^{\frac{n(n+1)}2};\ \text{both}: 2^{\frac{n(n-1)}2}
S: Count the "free" pairs for the property and raise 2 to that power. || "Not reflexive" etc.: subtract from the total of the bigger class. || For small sets with several properties, list cases by hand (start with the forced pairs).
E: Symmetric: $2^{10}=1024$; symmetric and reflexive: $2^6=64$; answer $960$.
P: 04:13,7

Q: If the domain of a composite function (logs, inverse trig, roots) is asked
R: "$\log_3\log_5(7-\log_2(x^2-10x+85))+\sin^{-1}|\frac{3x-7}{17-x}|$", "$\frac{\sqrt{x^2-25}}{4-x^2}+\log(x^2+2x-15)$", domain of $f\circ g$.
F: \sqrt u: u\ge0;\ \log u: u>0;\ \sin^{-1}u,\cos^{-1}u: |u|\le1;\ \frac1u: u\ne0
S: List the condition for each piece, from the outermost function inwards (for $\log_a\log_b(\ldots)$: inner log $>0$, i.e. argument $>1$). || Solve each inequality. || Intersect all conditions. || For $f\circ g$: $x$ in the domain of $g$ and $g(x)$ in the domain of $f$.
E: $\frac1{\sqrt{10+3x-x^2}}+\frac1{\sqrt{x+|x|}}$: $(-2,5)\cap(0,\infty)=(0,5)$, so $(1+a)^2+b^2=26$.

Q: If the range of a rational function is asked
R: "$f(x)=\frac{5-x}{x^2-3x+2}$ has range $(-\infty,\alpha]\cup[\beta,\infty)$", "$\frac{x^2+2x-15}{x^2-4x+9}$ is one-one/onto?", "$\frac{x^2}{1-x^2}$ surjective onto $A$".
F: y=\frac{P(x)}{Q(x)}\Rightarrow yQ(x)-P(x)=0,\ \ D\ge0
S: Put $y=f(x)$ and cross-multiply into a quadratic in $x$. || For real $x$, discriminant $\ge0$: an inequality in $y$. || Remove $y$-values that need excluded $x$, and treat the case where the $x^2$ coefficient vanishes. || The resulting set is the range (for surjectivity, the codomain must equal it).
E: $yx^2+(1-3y)x+2y-5=0$: $D=y^2+14y+1\ge0$ ⇒ $\alpha+\beta=-14$, $\alpha\beta=1$, $\alpha^2+\beta^2=194$.

Q: If onto functions or functions with value conditions are counted
R: "Onto $f:\{a,b,c,d,e\}\to\{1,2,3,4\}$ with $f(a)\ne1$", "$f(1)+f(2)=f(3)$", "$f(x)\le(x-3)^2+1$", "$f(mn)=f(m)f(n)$", "onto $f:S\times S\to S$ with symmetry".

S: Count all onto maps with inclusion–exclusion. || Use symmetry for a single-value restriction: each value is equally likely for $f(a)$. || For sum conditions, count pairs $(f(1),f(2))$ that make $f(3)$ valid; multiply by free choices. || For bounds, multiply the number of allowed values for each $x$.
