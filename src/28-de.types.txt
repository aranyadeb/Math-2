## If this type comes, solve like this
Q: If it is linear in $y$ (or in $x$) after rearranging
F: \frac{dy}{dx}+Py=Q\Rightarrow y\,e^{\int P}=\int Qe^{\int P}dx+C
N: Divide by the coefficient of $dy$. If $x$ and $y$ swap roles (e.g. $(\ln\cos y)^2\cos y\,dx-\ldots dy$), write $\frac{dx}{dy}+Px=Q$. Recognise $f'(y)\frac{dy}{dx}+Pf(y)=Q$ ⇒ put $t=f(y)$ (e.g. $t=\frac1{\ln\cos x}$).
P: 25:1,3,5,8,10,9,7

Q: If variables separate (possibly after partial fractions)
F: \int\frac{dy}{g(y)}=\int f(x)\,dx
N: $(x^2-4)dy=(y^2-3y)dx$: $\frac{dy}{y(y-3)}=\frac{dx}{x^2-4}$, both sides by partial fractions.
P: 25:2,26

Q: If it is homogeneous ($\frac{dy}{dx}=F(\frac yx)$)
F: y=vx\Rightarrow v+x\frac{dv}{dx}=F(v)
P: 25:6,12,13,17,28,23

Q: If it is Bernoulli or contains $(x+y)$ / $(y+1)$ combinations
F: \frac{dy}{dx}+Py=Qy^n\Rightarrow z=y^{1-n};\ \ \text{put } v=x+y\ \text{or } v=y+1
P: 25:4,11,26

Q: If geometry of tangents/normals gives the DE (intercepts, slopes)
F: \text{tangent meets } y\text{-axis at } y-xy';\ \ x\text{-axis at } x-\tfrac y{y'}
P: 25:16,21,24

Q: If order/degree or forming the DE of a family
F: \text{order}=\#\text{arbitrary constants};\ \text{eliminate them by differentiating}
P: 25:18,22,25

Q: If growth/cooling application
F: \frac{dT}{dt}=-k(T-T_s)
P: 25:19

Q: If an integral/limit equation defines the function
F: \text{differentiate both sides (Leibniz) to get a DE}
P: 25:14,15,20,27,29
